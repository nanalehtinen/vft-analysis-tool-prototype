        Guidance

        A walkthrough of how this prototype works and how to read what it produces.

        How scoring works

        This prototype demonstrates the intended workflow for the 2nd iteration of an AI-assisted, human-in-the-loop scoring tool, built on three parts:

        1. Deterministic rules. Total score, errors, temporal segmentation, and phonemic clustering follow explicit, mechanical rules from the manual. Two independent raters following these rules reached excellent agreement (ICC > 0.90). Human judgment is very unlikely to be required here; edge cases, if any arise, are flagged for review.
        2. AI-assisted semantic judgment. The second iteration of the tool runs semantic-relatedness judgments locally via an embedding model. This prototype demonstrates the intended mechanism using the manual's own worked examples.
        3. Human-in-the-loop review. When a cluster has more than one valid reading, the tool flags it for manual review. AI does not solve edge cases independently. This mirrors an inter-rater process, where semantic clustering agreement was found to be good, not excellent (ICC 0.75–0.90), in method validation specifically because of such cases.

        Reading your results

        • Total score — acceptable words generated, minus errors.
        • Errors — repetitions, categorical errors, paraphasias and nonwords, each tagged with its type.
        • Temporal parameters — words per time segment; requires audio, so it's unavailable for transcript input in this prototype.

        Then, two clustering readings — scored independently per the manual:

        • Task-congruent clustering uses the same domain as the task — phonemic clusters (shared sounds, rhymes) in a phonemic trial, semantic clusters (shared meaning) in a semantic trial. This is the reading behind Mean cluster size and Number of switches.
        • Task-discrepant clustering is the other domain showing up anyway — e.g. a participant grouping words by meaning ("kynä, kumi" — things related to writing) while doing a phonemic task. It gets its own count and mean cluster size, since it reflects a distinct strategy.
        • Cluster breakdown tables — every word accounted for, in the order the participant actually said it, including non-clustering single words.
